# Implementation plans

Task-by-task implementation plans produced from the designs in
[`../specs/`](../specs/README.md). Each plan is written for an engineer with no
context on this codebase: exact files, real test code, and the command to run at every
step.

A plan is a **snapshot of intent**, not a record of what shipped. Once its tasks are
done, the behaviour is described by the relevant module spec under
[`docs/system-specs/modules/`](../../system-specs/modules/README.md), and the plan
stays only as the record of how the work was sequenced.
