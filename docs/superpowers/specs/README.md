# Design specs

Validated designs produced by the brainstorming workflow, before they become
implementation plans. Each is dated and records the decisions taken, the options
rejected, and the assumptions that still need verifying.

These are **proposals at a point in time**, not descriptions of shipped behaviour.
Once a design ships, its behaviour is documented in the relevant module spec under
[`docs/system-specs/modules/`](../../system-specs/modules/README.md); the file here
stays as the record of why the design is what it is.
